# NexaCore — Responsive Multi-Page Website

A modern, responsive 3-page website created for **Week 2 — Task 1: Responsive Multi-Page Website**.

## Pages

- **Home** — hero, dashboard visual, stats, services preview and process.
- **Services** — detailed service cards and quality-focused approach.
- **Contact** — accessible contact form with client-side validation.

## Requirements Covered

- Semantic HTML structure
- Responsive navigation bar
- Reusable header/footer structure
- Mobile navigation menu
- Responsive desktop/tablet/mobile layouts
- Client-side form validation
- Interactive UI with JavaScript
- Light / dark theme toggle with saved preference
- Additional value/CTA sections for a richer landing-page experience
- Scroll reveal animations
- Keyboard-friendly controls
- ARIA labels and live validation feedback
- Reduced-motion support

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Git / GitHub
- GitHub Pages

## Run Locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Testing Checklist

- Test navigation between all 3 pages.
- Resize the browser across desktop, tablet and mobile widths.
- Test the mobile menu.
- Submit the contact form with empty/invalid fields.
- Submit a valid form and confirm the success state.
- Navigate using keyboard focus.
- Test with reduced-motion preferences enabled.

## Week 2 Deliverables

- Working responsive multi-page website

### Lessons / Next Iteration

Future improvements could include a real backend for form submissions, stronger content personalization, performance optimization with production assets, and automated accessibility testing.
